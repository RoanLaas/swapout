Wass good gamers, it's time to SwapOut. A homebrew version of DND with our own cool rules and spell systems. It's up to you to do all the fun campeign stuff but the spells can be handeled with this app.

## Folder Structure

Try to keep all the folders in the places they're meant to go:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies
- `resources`: The folder than contains images and shit like that
- `bin`: The folder that contains all the auto generated .class files

## Dependency Shit

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).
